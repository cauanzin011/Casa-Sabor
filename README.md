# Casa Sabor

Site responsivo para um restaurante fictício, desenvolvido com **HTML, CSS e JavaScript**.

O projeto simula a experiência de um restaurante moderno, com cardápio interativo, sistema de pedidos, carrinho e outras funcionalidades desenvolvidas com JavaScript.

## Sobre o projeto

O **Casa Sabor** foi desenvolvido como um projeto de estudo e portfólio, com o objetivo de praticar principalmente **JavaScript, manipulação do DOM, eventos, arrays, objetos e LocalStorage**.

A ideia foi criar uma interface que não fosse apenas visual, mas que também tivesse funcionalidades semelhantes às encontradas em um site real de restaurante.

## Funcionalidades

* Layout responsivo
* Cardápio organizado por categorias
* Filtro de produtos por categoria
* Sistema de pedidos
* Adição de produtos ao pedido
* Remoção de unidades de produtos
* Controle de quantidade
* Cálculo automático do valor total
* Persistência do pedido utilizando LocalStorage
* Visualização do pedido
* Menu mobile
* Status de funcionamento do restaurante
* Exibição do horário do pedido
* Mensagens e feedbacks para o usuário

## Tecnologias utilizadas
